# Проверка и чистка игроков CatWar — версия «Земля»
## 1. Что это за скрипт?

Это скрипт для Google Таблиц, который помогает проверять принадлежность игроков CatWar к нужной фракции и удалять из таблицы записи игроков, которые к ней не относятся.

Скрипт автоматически проверяет профили игроков на сайте CatWar, определяет их фракцию и составляет список записей, требующих внимания.

Основная задача скрипта — облегчить чистку таблиц от участников, которые больше не состоят в нужной фракции, и снизить количество ошибок при ручной проверке.

Скрипт предназначен для работы с Google Таблицами, в которых хранятся ID игроков CatWar.

## 3. Что умеет скрипт?

Скрипт выполняет три основные задачи.

### Проверка фракций

Скрипт читает ID игроков из настроенных диапазонов Google Таблицы и открывает соответствующие профили CatWar.

По результатам проверки каждая найденная запись получает один из статусов:

- **На чистку** — профиль указывает на фракцию, отличную от целевой, либо обнаружена предусмотренная скриптом ситуация со скрытой фракцией и Озёрной вселенной.
- **Ручная проверка** — автоматически определить фракцию не удалось, профиль недоступен, обнаружена ошибка или требуется дополнительная проверка.
- **Без отметки в результатах** — игрок состоит в целевой фракции «Крылатое племя», поэтому скрипт не добавляет его в список на чистку.

Также скрипт выявляет повторяющиеся ID в пределах одного проверяемого листа и отмечает такие случаи для ручной проверки.

### Удаление отмеченных игроков

Скрипт может удалить из исходной таблицы строки, которые получили статус «На чистку».

Перед удалением он:
1. Создаёт резервную копию всей Google Таблицы.
2. Проверяет, что ID игрока в исходной строке по-прежнему совпадает с ID из результатов проверки.
3. Сохраняет данные удаляемой строки в архив.
4. Удаляет строку из исходного листа.
5. Записывает результат действия в таблицу результатов.

Если исходный лист или строка не найдены, ID изменился либо возникла ошибка, скрипт пропускает удаление или отмечает ошибку.

**Важно:** статус «На чистку» сам по себе не означает, что строка уже удалена. Для удаления необходимо отдельно запустить соответствующую функцию.

### Восстановление удалённых записей

Если строка была удалена скриптом, её можно восстановить из архива.

Для восстановления скрипт использует сохранённые значения и формулы строки, а также информацию о первоначальном листе и номере строки.

Восстановление доступно только для записей со статусом архива «Удалён».

## 4. Как пользоваться скриптом?

Все основные действия доступны через меню **CatWar** в Google Таблице.

Если меню не появилось сразу после открытия таблицы, обновите страницу.

### Шаг 1. Проверка игроков

1. Откройте Google Таблицу, в которой установлен скрипт.
2. В верхнем меню выберите **CatWar → Проверить фракции**.
3. Дождитесь завершения проверки.
4. Откройте лист **«Результаты проверки»**.
5. Просмотрите записи со статусами «На чистку» и «Ручная проверка».

При необходимости откройте профиль игрока по ссылке в результатах и проверьте его вручную.

### Шаг 2. Удаление отмеченных записей

Перед удалением обязательно проверьте результаты и убедитесь, что записи действительно можно удалить.

1. Убедитесь, что лист «Результаты проверки» содержит актуальные данные.
2. Проверьте список игроков со статусом «На чистку».
3. Выберите **CatWar → Удалить отмеченных**.
4. Дождитесь завершения операции.
5. Проверьте столбец «Действие» на листе «Результаты проверки».

Скрипт удаляет только необработанные записи со статусом «На чистку», для которых указаны исходный лист, номер строки и корректный ID.

Записи со статусом «Ручная проверка» автоматически не удаляются.

### Шаг 3. Восстановление удалённой записи

1. Откройте лист **«Архив удалённых»**.
2. Найдите запись нужного игрока.
3. Убедитесь, что её статус — «Удалён».
4. Выделите ячейку в строке этой записи.
5. Выберите **CatWar → Восстановить выбранную запись**.
6. Дождитесь сообщения о результате операции.

Восстанавливайте запись только после проверки того, что она действительно должна вернуться в таблицу.

## 5. Что означают листы таблицы?

### «Общие баллы»

Исходный лист, в котором скрипт ищет ID игроков. В текущей конфигурации проверяется диапазон `C5:C170`.

### «Результаты проверки»

Лист с результатами автоматической проверки. Он содержит:

- исходный лист и номер строки;
- ID игрока;
- определённую фракцию;
- результат проверки;
- ссылку на профиль;
- причину проверки;
- результат удаления или другую информацию о действии;
- дату действия.

При новом запуске проверки содержимое этого листа формируется заново. Поэтому предыдущие результаты, включая записи о выполненных действиях, могут быть перезаписаны.

### «Архив удалённых»

Лист, в котором сохраняются сведения об удалённых строках, исходные значения и формулы.

Архив нужен для восстановления записей и сохранения информации об удалённых участниках.

Некоторые столбцы архива являются служебными и скрыты. Не удаляйте и не редактируйте их вручную.

## 6. Важные предупреждения

- **Перед удалением создаётся резервная копия всей Google Таблицы.** Она сохраняется на Google Диске. Не удаляйте её, пока не убедитесь, что чистка завершилась корректно.
- Скрипт работает с исходными строками таблицы. Перед запуском удаления убедитесь, что результаты проверки актуальны.
- Если после проверки таблицу редактировали вручную, скрипт может пропустить запись, если обнаружит, что ID в исходной строке изменился.
- Не удаляйте и не переименовывайте листы «Результаты проверки» и «Архив удалённых» без предварительного согласования с разработчиком.
- Если профиль не удалось проверить автоматически, это не обязательно означает, что игрок покинул фракцию. Используйте ручную проверку.
- Скрипт зависит от доступности CatWar и структуры страниц профилей. Изменения на сайте могут повлиять на корректность автоматического определения фракции.
- Не запускайте удаление повторно, если предыдущая операция ещё выполняется.

## 7. Возможные проблемы

**Скрипт не находит нужных игроков.**

Проверьте, что ID находятся в настроенном диапазоне исходного листа и записаны корректно.

**Появился статус «Ручная проверка».**

Откройте профиль игрока по ссылке и проверьте фракцию самостоятельно. Также проверьте причину, указанную в результатах.

**Удаление не произошло.**

Посмотрите столбец «Действие». Скрипт мог обнаружить изменившийся ID, отсутствующий лист, некорректную строку или другую ошибку.

**Не удалось восстановить запись.**

Проверьте, что выбрана правильная строка архива и её статус — «Удалён», а исходный лист существует.

**Возникла другая ошибка.**

Не изменяйте код самостоятельно. Передайте описание ошибки и, если возможно, текст сообщения разработчику.
